# Evaluation protocol

The qualification set fixes 12 queries before comparison. Each method reports Recall@1/5/10,
MRR, median rank and mean rank. Index evaluation reports overlap Recall@5 against the exact
reference and mean latency. Conversational fixtures report intent accuracy, traceability and
unsupported-answer rate.

Official Flickr8k test remains locked. No reported qualification value may be relabeled as an
official CLIP, OpenCLIP, FAISS or Flickr8k result.
