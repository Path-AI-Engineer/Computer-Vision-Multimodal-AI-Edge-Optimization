# Demo script

1. Open Retrieval Studio and search `dog running on a beach` in Hybrid/Exact mode.
2. Point to the image ID, caption evidence and semantic/lexical/hybrid scores.
3. Switch to Visual query, select `vl-005` and retrieve similar images.
4. Open Refinement Room; send `people in a city`, then `only night`, `exclude train` and `explain`.
5. Show the live typed state and cited result IDs.
6. Open Benchmark and compare TF-IDF, semantic and hybrid qualification results.
7. Open Failure Atlas and explain why negation and spatial relations are not claimed.
8. Finish in System Cards with model/index compatibility and locked official benchmarks.
