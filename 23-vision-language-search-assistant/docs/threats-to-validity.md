# Threats to validity

- The qualification corpus is tiny, generated and vocabulary aligned.
- TF-IDF can achieve perfect ranks because captions contain explicit target terms.
- The semantic adapter is deterministic rather than learned.
- The approximate index is a quantization proxy, not a scalable ANN structure.
- Mean sub-millisecond latency does not predict production latency.
- Conversational fixtures cover grammar behavior, not open-ended language understanding.

These limitations are visible in the UI and machine-readable reports.
