# Vision-Language Retrieval Studio design system

- Product pattern: evidence-first search directory with search as the primary action.
- Style: OLED research workspace; restrained glow, dense evidence and quiet surfaces.
- Primary surface: `#060b12`; cards: `#0a151d`; text: `#edf6f5`.
- Retrieval accent: `#65e6d4`; comparison: `#7c8cff`; warnings: `#f6b85f`.
- Typography: Fira Sans with Fira Code/Cascadia Code for IDs and versions.
- Cards use 14–20px radii, one-pixel borders and no hover transforms.
- Interactive transitions stay between 150–250ms and never shift layout.
- Focus rings use the retrieval accent. All images require descriptive alt text.
- Responsive targets: 390, 768, 1024 and 1440 pixels without horizontal overflow.
- `prefers-reduced-motion` disables decorative animation.
- Avoid emoji icons, ungrounded marketing claims and charts without source labels.
