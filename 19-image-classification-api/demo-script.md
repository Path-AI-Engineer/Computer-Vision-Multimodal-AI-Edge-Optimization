# Demo script

1. Open **Overview** and point out the qualification banner and locked official test.
2. Open **Classify**, select a public sample and run a real inference.
3. Explain Top-5 probability, abstention threshold, artifact version and latency.
4. Upload an invalid file to show the API rejecting unsafe content with a clear state.
5. Open **Evaluation** and identify the exact procedural-validation scope.
6. Open **Error gallery** and inspect low-confidence or incorrect decisions.
7. Open **Model comparison** and show that unexecuted deep candidates have no metrics.
8. Finish at **Responsible use**: confidence is not certainty and this is not veterinary advice.
