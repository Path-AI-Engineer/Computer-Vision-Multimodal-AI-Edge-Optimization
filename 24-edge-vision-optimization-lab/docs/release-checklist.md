# Release checklist

- [x] Qualification dataset and artifacts are independent of Project 19.
- [x] Quality, latency, size and sparsity are persisted per variant.
- [x] Raw timing samples and environment controls are versioned.
- [x] Pareto and recommendations are derived from persisted evidence.
- [x] API and interface consume the same immutable registry.
- [x] NOT_RUN and failed parity states remain visible.
- [x] Docker and AWS App Runner release assets are versioned.
- [ ] Oxford-IIIT Pet, MobileNetV3 and ONNX Runtime experiments executed.
- [ ] Playwright desktop/mobile suite executed outside managed restrictions.
- [ ] Production container built and smoke-tested.
- [ ] AWS deployment explicitly authorized and verified.
